# MST Flutter Test Task

Тестовое задание, выполненное на Flutter.

## Описание проекта

Приложение демонстрирует простой сценарий подписочной модели и включает следующие экраны:

1. Онбординг из двух экранов
2. Экран подписки (Paywall)
3. Главный экран приложения

После оформления подписки её состояние сохраняется локально на устройстве. При последующих запусках приложения пользователь автоматически попадает на главный экран без повторного прохождения онбординга и экрана подписки.

## Реализованный функционал

### Онбординг

* Реализован с использованием `PageView`
* Содержит два информационных экрана
* Добавлены индикаторы текущей страницы
* Кнопка перехода к следующему шагу

### Экран подписки (Paywall)

* Доступны два тарифных плана:

  * Monthly (ежемесячная подписка)
  * Yearly (годовая подписка со скидкой)
* Возможность выбора тарифа
* Диалог подтверждения покупки
* Диалог успешной активации подписки

### Главный экран

* Отображается после успешной покупки
* Содержит информационный баннер о наличии Premium-подписки
* Демонстрирует основной контент приложения

### Сохранение состояния подписки

Для хранения информации об активной подписке используется `SharedPreferences`.

При запуске приложения выполняется проверка статуса подписки:

* если подписка активна — открывается главный экран;
* если подписки нет — отображается онбординг и экран подписки.

```text
        ↓

        ↓

        ↓

        ↓
Успешная активация подписки

```

```text

Главный экран
```

## Запуск проекта

Установить зависимости:

```bash
flutter pub get
```

Запустить приложение:

```bash
flutter run
```

## Примечание

В рамках тестового задания реализована эмуляция покупки подписки без подключения реальных платёжных систем (Google Play Billing / App Store StoreKit). Основное внимание уделено пользовательскому сценарию, навигации и сохранению состояния подписки.
